# 📦 Система учета бракованных материалов

Web-приложение для учета и управления бракованными материалами (ЛДСП, столешницы, кромка и др.) с разделением на административную и пользовательскую части.

---

## 📋 Функционал

### 👑 Административная часть
- **CRUD операции** — создание, редактирование, удаление записей
- **Синхронизация с Excel** — загрузка данных из CSV файлов
- **Полная замена данных** — очистка таблиц и загрузка новых данных
- **Сортировка** по всем столбцам таблицы
- **Поиск** по любой колонке
- **Просмотр фотографий** в модальном окне
- **Статистика** просмотров страниц

### 👤 Пользовательская часть
- **Просмотр таблиц** со всеми категориями материалов
- **Сортировка** по столбцам (клик по заголовку)
- **Поиск** по любой колонке
- **Просмотр фотографий** в модальном окне

### 📊 Доступные категории
1. Ивацевичи BySpan
2. Эггер ДСП
3. Кроноспан
4. МДФ
5. Скинали, фальшпанели
6. Эггер столешницы
7. Столешницы Кедр
8. ХДФ
9. Фанера
10. Кромка, бортики
11. Пластик

## 🚀 Быстрый старт

### 1. Клонировать репозиторий
```bash
git clone https://github.com/ваш-username/ваш-репозиторий.git
cd ваш-репозиторий
```

### 2. Настройка базы данных
1. Импортируйте файл дампа базы данных (если есть)
2. Настройте подключение к БД в файле:
   ```
   Timberland/Admin/modules/db_connection.php
   ```

### 3. Настройка конфигурации
Создайте файл конфигурации (если требуется):
```
Timberland/config.php
```

### 4. Загрузка на хостинг
Просто загрузите папку `Timberland` в корневую директорию вашего сайта.

## 📝 Синхронизация с Excel

1. Сохраните Excel файл как **CSV (UTF-8)**
2. В админ-панели нажмите **"Синхронизировать"**
3. Выберите CSV файл и загрузите
4. Данные будут автоматически распределены по таблицам

**Важно:** CSV должен быть в кодировке **UTF-8**!

## 🚨 Возможные проблемы и решения

### Ошибка 500
- Проверьте права доступа к папкам и файлам
- Убедитесь, что в `php.ini` включены ошибки

### Кракозябры в тексте
- Убедитесь, что CSV сохранён в **UTF-8**
- Проверьте кодировку подключения к БД

### Не загружаются фото
- Проверьте права на папку `uploads/`
- Убедитесь, что путь к файлам корректен
